# Feature

## Sections

### Goal

What this enables users to do. Outcomes, not implementation.

### Requirements

Specific behaviors, inputs/outputs, error handling.

#### Out of Scope

What this does not include. Skip unless there's an adjacent thing a reasonable reader would assume is included.

### Design

Include subsections selectively.

#### Approach

High-level implementation. Reference existing patterns. Skip for trivially-designed features. Don't enumerate thin, unevaluated options. State the chosen approach, or the goal plus acceptance criteria, and leave option-weighing to a real decision.

#### Changes

Files and components to modify. Skip when Related Code already names the files.

#### Open Questions

Decisions needed before or during implementation. Skip when there are none.
