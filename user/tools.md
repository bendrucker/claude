# Tools

My setup runs on these. Where a dotfiles topic exists, detail lives in `~/.dotfiles/<topic>/README.md`.

## macOS

- Ghostty: terminal emulator
- herdr: multiplexer
- zsh, atuin, zoxide, fzf, Neovim: shell and editor
- mise, Homebrew: tooling installs
- Claude Code: sessions in herdr panes
- Moshi: `moshi-hook`, the Mac side of the iOS client, fed by Claude Code hooks
- Tailscale: tailnet
- tailgate: local MCP servers exposed to claude.ai
- Things 3: personal tasks and future-dated work
- Raycast: launcher
- 1Password (`op run`), Secretive: secrets, SSH keys

## iOS

- Moshi: main remote client, attaching to herdr over mosh
- Tailscale: access to the Mac and tailnet services
- Claude app: Remote Control of Claude Code sessions and chat with connectors like Things
- Things 3: same tasks, synced
