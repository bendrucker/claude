# Docs

State the conclusion and link the evidence behind it: the PR's Evidence section (`.../pull/N#evidence`) or the issue comment that holds the table. Raw data stays there, never in the doc: counts, percentages, per-project tallies, before/after measurements. When the PR body lacks the data, post it as a PR comment first and link that comment.

A retirement threshold (`retire it when X stays under 10% for four weeks`) is a criterion and belongs in the doc.
