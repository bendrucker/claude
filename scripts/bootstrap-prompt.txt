Please install my complete Claude Code configuration by running:

curl -fsSL https://raw.githubusercontent.com/bendrucker/claude/main/scripts/bootstrap-remote.sh | bash

This will:
- Install my marketplace (bendrucker) and external marketplaces (astral-sh, ast-grep, worktrunk)
- Copy my full user configuration (permissions, sandbox settings, all enabled plugins)
- Install user-level instructions (CLAUDE.md)
- Filter out macOS-specific settings on Linux/remote platforms

After completion, settings will take effect on the next user message (Agent SDK) or session restart (CLI).
