# claude-code

Meta-tools for Claude Code configuration and customization.

## Skills

- **skills**: Creating and optimizing Claude Code Skills including activation patterns, content structure, and development workflows
- **session**: View current session information including ID, duration, tool usage stats, and log file path

## Agents

- **claude-code-hooks.md**: Developing Claude Code hooks for automated workflows
- **claude-md.md**: Creating and organizing CLAUDE.md project memory files

## Testing

```bash
npx vitest run plugins/claude-code/
```
