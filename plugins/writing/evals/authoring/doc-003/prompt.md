Write API docs in the README for convex-firebase, my convex (Angular ORM) plugin that binds models to Firebase, read-only. Firebase must be global as window.Firebase, wired in as an injectable service. Collection subscriptions skip child_moved, and hand-reordering or deleting collection entries corrupts the internal index. `$ref` defaults to `$path(false)` when a collection arg is passed, `$path(true)` otherwise.
