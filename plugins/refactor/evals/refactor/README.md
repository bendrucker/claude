# `refactor` Eval

A native `claude plugin eval` suite for the `refactor` plugin's skills, with the Ports section of [`testing.md`](../../../../user/rules/testing.md) injected as context. Each case scaffolds a small repo with `fixture.sh` and asks for a port or a nearby change, graded with and without the skill.

The `port-*` cases ask for a shell script to be reimplemented in TypeScript. Each original carries behavior a straight rewrite drops: `uniq -c` padding and a silent exit under `pipefail`, a trailing dash a caller depends on, and output that depends on the clock. Graders check that the session ran both versions on the same inputs, kept the original, and handled the case's quirk. `tests-node-to-bun` converts a node:test suite and checks that its exact-message and error-type assertions survive. The `quiet-*` cases change behavior on purpose, and a `quiet` grader scored on both arms fails when the skill fires on them. `split-orders`, `port-dedupe-slugify`, and `port-upstream-semver` cover the other skills and the library-replacement path: a split that must keep import-time registration and the exported names, three diverged slug functions, and a hand-rolled semver comparator whose prerelease ordering differs from the library's. `port-many-clis` moves six CLIs to a strict argument parser, where a README, two shell scripts, and a CRLF config file pass spellings and values only the lenient parser accepted. `port-wrapper-exit` asks for a cutover behind a harness whose wrapper prints exit codes into digit-masked stdout. A signed-off exemption there hides a second exit-code change. Cases are tagged `dev` or `holdout`.

The `mined` cases rebuild failures from real migrations, each with a trap the prompt never names. `port-both-sides-fail` asks for a cutover behind a 14/14 harness whose carrier stub never finds its recording, so every export input crashes identically on both sides and hides two export bugs. `port-exempt-direction` asks to finish a port whose signed-off strict-parsing exemption also covers `prune --keep 0`, which the old code refused and the port runs, deleting every snapshot, and a cron script that passes a flag the sign-off note says nobody passes. `port-degenerate-rerun` asks for a parity rerun, where the generic runner skips the stored wrapper that sets `FX_RATES`, so a later commit's lowercase-currency divergence shows only through it. `port-quirk-shim-boundary` moves a CLI to a parser that keeps the `=` in an attached `-v=42`, where the obvious shim strips the `=` from formulas. `port-library-edge` swaps a hand-rolled spawn timer for `Bun.spawn`'s `timeout`, which treats 0 as no timeout and can't tell its own SIGKILL from an outside one. `port-ci-gate` asks for lint only and a ready verdict, where the stricter build type check and a source-scanning stdout check, which only the CI workflow runs, fail on a natural port that passes lint, `typecheck`, and `bun test`.

These cases grade the repository state, not the trace. The session's Bash can write neither the working tree nor `.git`, so nothing can be pushed or committed. Each fixture instead sources [`scripts/grade-watch.sh`](scripts/grade-watch.sh), which starts a watcher outside the sandbox: whenever a file in the working tree changes, it copies the tree aside, runs the case's hidden check on the copy against a pristine snapshot of the fixture commit, and writes one verdict line per check to `.git/eval/verdicts`. A check takes a few seconds, so the `{ source: file, path: .git/eval/verdicts }` graders read the state from shortly before the session ended. A check that needs the port to exist first prints `not ported` until it does.

`gh workflow run eval.yml --ref <branch> -f suite=plugins/refactor/evals/refactor` runs it in CI. `bun evals/native/run.ts plugins/refactor/evals/refactor -- --tag dev` runs it locally. Results land in the gitignored `results/<timestamp>/`.

The timesheet and duration cases (`port-finish-matchrate`, `port-audit-tests`, and their `-invoked` twins), `port-many-clis`, and `port-wrapper-exit` grade hidden-input behavior through a token line their test preload prints. That line only reaches the trace when the session leaves its last `bun test` unfiltered, so a native score there measures output filtering as much as the fix. For those cases, run with `--keep-temp` and score with `bun scripts/rescore.ts <results>/aggregate-result.json`, which reruns the pristine preload against each run's final workspace and prints the native and rescored value per run. The kept directories live under `$TMPDIR`, so in a session whose Bash calls each get a fresh `/tmp`, run the eval and the rescore in the same command, or point `TMPDIR` at a directory that persists.
