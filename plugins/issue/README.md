# Issue Plugin

Work on issues from GitHub, Linear, or GitLab.

## Contents

- **Skill (`issue`)**: Implement a feature or fix based on a tracked issue
- **Skill (`issue:refine`)**: Expand brief descriptions into detailed issues for bugs, features, and refactors
- An eval suite, [`evals/issue-refine`](evals/issue-refine/), A/Bs `issue:refine` on synthetic briefs against regex graders built from a labeled rubric
