Read only the issue between the <issue> lines, above any "Agent Context" heading. Where the body uses lists, they carry the substance of concise writing, not just its shape: each item makes one point in a short fragment or sentence, items are parallel, no item restates another or the prose around it, and a list holds only as many items as there are distinct points. A list of multi-clause sentences, or paragraphs chopped into bullets, fails. A body with no lists passes. For example, "- `access`: owner, shared, or org" passes, and "- The access property is added so that we can later distinguish between owners and other users, which matters because the dashboard needs it" fails.
