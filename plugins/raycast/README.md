# Raycast

Raycast extension development patterns, API, and Store publishing.

## Contents

- **Skill**: `raycast` covers extension development, with references for manifest, components, hooks, AI tools, and Store publishing
- **Skill**: `develop` runs the dev server, builds, lints, and launches a command by deeplink
- **Skill**: `publish` preflights an extension for the Store and hands the branch to `/ship`
