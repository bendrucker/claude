# `refactor` Eval

A native `claude plugin eval` suite for the `refactor` plugin's skills, with the Ports section of [`testing.md`](../../../../user/rules/testing.md) injected as context. Each case scaffolds a small repo with `fixture.sh` and asks for a port or a nearby change, graded with and without the skill.

The `port-*` cases ask for a shell script to be reimplemented in TypeScript. Each original carries behavior a straight rewrite drops: `uniq -c` padding and a silent exit under `pipefail`, a trailing dash a caller depends on, and output that depends on the clock. Graders check that the session ran both versions on the same inputs, kept the original, and handled the case's quirk. `tests-node-to-bun` converts a node:test suite and checks that its exact-message and error-type assertions survive. The `quiet-*` cases change behavior on purpose, and a `quiet` grader scored on both arms fails when the skill fires on them. `split-orders`, `port-dedupe-slugify`, and `port-upstream-semver` cover the other skills and the library-replacement path: a split that must keep import-time registration and the exported names, three diverged slug functions, and a hand-rolled semver comparator whose prerelease ordering differs from the library's. `port-many-clis` moves six CLIs to a strict argument parser, where a README, two shell scripts, and a CRLF config file pass spellings and values only the lenient parser accepted. `port-wrapper-exit` asks for a cutover behind a harness whose wrapper prints exit codes into digit-masked stdout. A signed-off exemption there hides a second exit-code change. The `candidates-*` cases ask for a ranked survey of a repository with seeded targets and decoys: three regex escapers (one missing `|`), a JSON deep clone, and a team-unit estimate parser that should stay in one, and a multi-responsibility server, three drifted email normalizers, two identical files in separately published zero-dependency packages, and a large data table in the other. Graders check that the report names the seeded targets with a difference the session ran, rejects the decoys with a reason, and leaves the source unchanged. Cases are tagged `dev` or `holdout`.

`gh workflow run eval.yml --ref <branch> -f suite=plugins/refactor/evals/refactor` runs it in CI. `bun evals/native/run.ts plugins/refactor/evals/refactor -- --tag dev` runs it locally. Results land in the gitignored `results/<timestamp>/`.

The timesheet and duration cases (`port-finish-matchrate`, `port-audit-tests`, and their `-invoked` twins), `port-many-clis`, and `port-wrapper-exit` grade hidden-input behavior through a token line their test preload prints. That line only reaches the trace when the session leaves its last `bun test` unfiltered, so a native score there measures output filtering as much as the fix. For those cases, run with `--keep-temp` and score with `bun scripts/rescore.ts <results>/aggregate-result.json`, which reruns the pristine preload against each run's final workspace and prints the native and rescored value per run. The kept directories live under `$TMPDIR`, so in a session whose Bash calls each get a fresh `/tmp`, run the eval and the rescore in the same command, or point `TMPDIR` at a directory that persists.
