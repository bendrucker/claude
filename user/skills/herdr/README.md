## Cache Discipline

The file states once that `herdr <group> <command> --help` enumerates every enum flag and every default. Everything downstream is what a `--help` lookup cannot supply. Adding a flag table needs a reason that pointer does not already cover.

## Removal

The skill is model-invocable and spends its description on every session. If the session index shows loads arriving only through `/herdr`, the natural-language triggers are inert, and the description should shrink to the argument-hint verbs.
