Run with `PROMPTFOO_CONFIG_DIR=$HOME/.cache/promptfoo bunx promptfoo eval -c plugins/review/skills/follow-up/evals/promptfooconfig.yaml` from the repo root. Both the skill under test and the grader authenticate through the logged-in Claude Code CLI, so a local run needs no API key. Leave `ANTHROPIC_API_KEY` unset, since the provider hands its environment to the Claude Code subprocess and an API key there takes precedence over the claude.ai login. Set `ANTHROPIC_GRADER_API_KEY` to grade against the API instead.
