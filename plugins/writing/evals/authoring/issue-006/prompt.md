File an issue on SumoLogic/fluentd-kubernetes-sumologic, not my repo. The pod-name stripping assumes two random suffixes only when the second-to-last dash segment parses as a number, but ReplicaSets have used an encoded, non-numeric pod-template hash since k8s 1.8 (kubernetes/kubernetes#51538), so a name like `app-556455c97c-k8tdx` on k8s 1.11 reads as one suffix, not two. Kubernetes also plans to encode the hash itself (kubernetes/kubernetes#66094), so numeric detection won't hold either way going forward. No fix proposed yet, just flagging it.
